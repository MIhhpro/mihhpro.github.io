## Measurement scope

`tests/loading-audit.html` is an internal same-origin iframe harness using browser Navigation/Resource/Paint/Layout Shift APIs and a 1.5-second post-font observation window. It measures homepage, About, Contact and English privacy pages without submitting forms. It uses an ordinary desktop browser cache, localhost delivery, an unthrottled CPU/network and synthetic iframe viewports. It is not Lighthouse, a real-device test, a cold-cache benchmark or field Core Web Vitals; missing LCP values are not zero. Do not publish this test page or claim a percentage speed gain from these noisy samples.

Baseline desktop (1280 × 800): load events 176/107/68/41 ms; observed layout-shift sums 0.0915/0.0875/0.0875/0.1381. Remote Google font origins were present. After local fonts: load events 182/84/53/39 ms; no external resource origins before interaction. The initial index was subsequently found to move the main content by 24px during setup, and its startup CSS was corrected. Final measurements are recorded below after verification.

Public homepage HTTP-only samples: 200 in all three; TTFB 674/116/99 ms and total response 674/121/99 ms; 5,436 transferred bytes with gzip requested. These are three real network samples from this machine, not whole-page render speed. They assess the existing live site, not these unpublished changes.

Final local samples, in the same page order (home / About / Contact / English privacy):
